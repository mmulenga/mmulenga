Do not edit these files by hand.

## Fonts

**Martian Mono** — used for the header and section headings. Copyright 2021 The Martian
Mono Project Authors, <https://github.com/evilmartians/mono>. Licensed under the SIL Open
Font License 1.1; the full text is at `tools/vendor/MartianMono-OFL.txt`. Each SVG embeds
a subset containing only the glyphs that file needs.

**DejaVu Sans Bold** — not embedded. It is used at build time only, to measure text so the
badges can be sized, and appears in the badge font stack as a fallback. Licensed under the
Bitstream Vera and Arev fonts licenses; full text at `tools/vendor/DejaVuSans-LICENSE.txt`.
